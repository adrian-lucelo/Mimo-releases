# Mimo Studio

Software de projeção para igrejas: arte e vídeo na tela, letras de louvor, Bíblia, cronômetros e retorno para o ministério e para o pastor. Funciona no **Windows** e no **macOS**.

Este repositório publica as **versões do aplicativo** (instaladores). O código-fonte não é público.

## Baixar

Abra a página de [**Releases**](../../releases/latest) e baixe o instalador do seu sistema:

- **Windows:** arquivo `.exe` (ou `.msi`)
- **macOS:** arquivo `.dmg`

O próprio aplicativo avisa quando existe uma versão nova (Configurações › Atualizações).

## Observações sobre a instalação

Nesta fase os instaladores ainda **não são assinados digitalmente**, por isso o sistema pode mostrar um aviso na primeira vez:

- **Windows:** se aparecer "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo**.
- **macOS:** se disser que o app não pode ser aberto, clique com o botão direito no app e escolha **Abrir**.

## Bíblias, letras e conteúdo

O Mimo Studio não inclui textos bíblicos nem letras de música. Você adiciona os arquivos de Bíblia (JSON) que tiver direito de usar, em **Bíblia › Versão › Adicionar**. Respeitar os direitos autorais desse conteúdo é responsabilidade de quem o utiliza.
